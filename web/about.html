University project

About SmartHabit

An educational machine-learning application that turns behavioural and demographic inputs into a smartphone-addiction risk estimate for reflection—not diagnosis.

Project purpose

SmartHabit demonstrates an end-to-end computational-intelligence workflow: trained model, validated API and accessible web interface.

Reflect on habits

Users enter a snapshot of their routine and receive an educational probability estimate with responsible risk wording.

Apply machine learning

The project preserves training-time feature engineering and preprocessing before applying the saved LightGBM model.

Communicate responsibly

Results include limitations, privacy-focused language and a non-diagnostic disclaimer.
